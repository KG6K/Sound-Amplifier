# Contributing to Sound Amplifier

We welcome contributions to Sound Amplifier (`io.github.kg6k.soundamplifier`)!

## Development Setup

1. Clone this repository.
2. Open the project in Android Studio (Ladybug / Koala or newer).
3. Ensure JDK 17+ and Android SDK 35 are installed.
4. Sync Gradle and run on an Android device or emulator running Android 10 (API 29) or above.

## Code Style

- Kotlin 2.0+ idiomatic coding conventions.
- Follow `.editorconfig` formatting rules.
- Maintain Material 3 guidelines and background service lifecycle safety.
